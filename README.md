# Сырой огонь — ресторан авторской кухни

Лендинг ресторана «Сырой огонь» (Екатеринбург): меню с вкладками,
фотогалерея, история, бронирование столика.

Статический сайт: `index.html` + `styles.css` + `custom.css` + `script.js`.
Сборка не требуется, деплой — Vercel.

## Разделы

- Первый экран с видео на открытом огне
- `01 / Меню` — вкладки «Кухня» и «Напитки», раскрытие полного меню
- Галерея из 4 кадров (стрелки, точки, клавиатура)
- `02 / История` — открытая кухня и цитата обозревателя
- `03 / Контакты` — адрес, время, бронирование

## Локальный запуск

```bash
python3 -m http.server 8000
```

## Статус

Кейс из портфолио, самостоятельная реализация без сторонних сборок и бейджей.
